관리자 계정으로만 로그인됩니다. 권한이 없는 계정은 읽기 전용으로 유지됩니다.
※ 편집 권한은 서버(RLS)에서 최종 확인하므로, 로그인 없이는 저장이 거부됩니다.

설정

팀원·변전소·작업종류·범례를 변경하려면 관리자 로그인이 필요합니다. 현재는 읽기 전용입니다.

순서는 일정 편집창의 버튼 순서와 같습니다. 퇴직·전출 인원은 삭제하세요.

색을 바꾸면 해당 분류의 모든 일정 배경이 즉시 반영됩니다.

관리자 계정(profiles.role = 'admin')만 편집할 수 있습니다.
계정 추가·권한 부여는 Supabase 대시보드에서 하며, 편집 차단은 서버(RLS)에서 이루어지므로 로그인 없이는 저장이 거부됩니다.

비워두면 로컬 저장 모드로 동작합니다(브라우저에만 저장, 새로고침해도 유지).
입력하면 Supabase Realtime 구독이 켜지고, 관리자가 수정하는 즉시 모든 배포용 화면이 자동 갱신됩니다. 테이블 생성 SQL은 함께 드린 supabase_schema.sql을 실행하세요.

월 단위 백업을 권장합니다. 가져오기는 현재 데이터를 덮어씁니다.

공유

배포용 링크는 ?view=1 이 붙어 관리자 버튼이 숨겨진 읽기 전용으로 열립니다.
